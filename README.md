# Экзаменатор — версия для GitHub и тестовой публикации

В комплекте **1106 автоматически извлечённых вопросов**, без исходных аккаунтов, паролей и результатов. Вопросы и ключи не прошли полную проверку. Банк: `questions_seed.sqlite`.

## Публикация через Render (демонстрационный режим)

1. Загрузите **содержимое** этой папки в приватный GitHub-репозиторий (не сам ZIP). Проверьте, что `questions_seed.sqlite` загружен.
2. На render.com выберите New → Blueprint, подключите репозиторий, подтвердите `render.yaml` и тариф Free.
3. При создании сервиса укажите `ADMIN_PASSWORD` (новый длинный пароль, минимум 12 символов). Не добавляйте пароль в файлы GitHub. `SECRET_KEY` Render сгенерирует сам.
4. После публикации откройте URL `https://<имя>.onrender.com` в Chrome на iPhone. Вход: `admin`, пароль из `ADMIN_PASSWORD`.

## ВАЖНО: ограничения бесплатной версии

**Временная база данных в `/tmp`**: после перезапуска/переразмещения Render результаты, добавленные пользователи, отредактированные вопросы и загруженные изображения могут исчезнуть. Для реальной группы нужна постоянная внешняя БД и файловое хранилище. Эта версия подходит для проверки интерфейса и демонстрационных тестов, **не для учёта успеваемости**.

Сессии/CSRF, ограничение числа попыток входа и защищённые cookies включены, но полноценный аудит безопасности и проверка импорта не проводились. Длинные/развёрнутые ответы оцениваются вручную; математическая эквивалентность формул не проверяется. При 6 типах вопросов равные доли обеспечиваются только при достаточном количестве вопросов каждого типа. Файлы с рисунками из исходных DOCX/PDF не импортируются автоматически.

## Локальный запуск

Для HTTP на локальном компьютере задайте `PUBLIC_HTTPS=0`, `ADMIN_PASSWORD` и `SECRET_KEY`, затем `pip install -r requirements.txt` и `python app.py`.
